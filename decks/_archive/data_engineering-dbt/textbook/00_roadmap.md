# dbt Basic Roadmap

이 문서는 `projects/dbt_basic` 실습 튜토리얼을 완주하기 위한 **전체 목차이자 트래킹 대시보드**입니다.
각 챕터 문서를 읽고 목표를 달성할 때마다, 이 로드맵으로 돌아와 해당 챕터에 완료(`x`) 표시를 남기며 진행도를 관리하세요.

## Main Chapters

- [ ] `01_sources.md`: 원천 데이터 관리 (Sources)
- [ ] `02_models.md`: 프로젝트 구조와 모델 작성
- [ ] `03_jinja_macros.md`: Jinja, ref, source, macro
- [ ] `04_testing.md`: 데이터 테스트 추가
- [ ] `05_docs.md`: 문서화 (Docs)
- [ ] `06_seeds.md`: 기준 데이터 적재 (Seeds)
- [ ] `07_snapshots.md`: 이력 관리 (Snapshots)
- [ ] `08_advanced_features.md`: 기초 이후의 기능
