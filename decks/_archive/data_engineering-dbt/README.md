# dbt

과거 `prac-datalake` monorepo의 `projects/dbt_basic`에서 옮겨 보존한 archived deck이다.

## Content

- [학습 로드맵](textbook/00_roadmap.md)
- `dbt_project.yml` — 당시 dbt project 설정
- `profiles.yml` — 로컬 DuckDB profile

이 자료는 당시 monorepo의 데이터 경로와 root dependency 환경을 전제로 작성되었다. Migration에서는 학습 자료와
project-local 설정을 보존하고, monorepo 공용 scaffolding과 생성 데이터는 옮기지 않았다.
