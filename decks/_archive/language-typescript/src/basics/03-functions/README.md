# 03. Functions (함수)

함수는 애플리케이션의 로직을 담당하는 핵심 단위입니다. TypeScript를 사용하면 매개변수와 반환값의 타입을 명확히 정의하여
"예상치 못한 동작"을 원천 차단할 수 있습니다.

---

## 📘 주제별 실습 안내

### 1. 기본적인 함수 타입 (Basic Functions)

- **파일**: `01-basic-functions.ts`
- **설명**: 매개변수와 반환 타입(Return Type)을 명시하는 방법을 배웁니다.

### 2. 매개변수 활용 (Parameters)

- **파일**: `02-parameters.ts`
- **설명**: 
  - **선택적 매개변수**: 인자를 생략할 수 있게 합니다.
  - **기본값 매개변수**: 인자가 없을 때 사용할 기본값을 지정합니다.

### 3. 나머지 매개변수 (Rest Parameters)

- **파일**: `03-rest-parameters.ts`
- **설명**: 가변 인자를 배열 형태로 안전하게 전달받는 방법을 학습합니다.

---

## 💡 함수 정의의 정석

```typescript
function 함수이름(인자: 타입): 반환타입 {
  return 결과;
}
```

- 반환값이 없는 함수는 `void` 타입을 사용합니다.
- 화살표 함수(`const fn = () => ...`) 형식에서도 동일한 규칙이 적용됩니다.

---

> [!TIP]
> TypeScript는 함수 호이스팅이나 스코프 규칙은 JavaScript와 동일하게 따르지만, 오버로딩(Overloading)과 같은 정적 언어
> 특유의 강력한 기능을 추가로 제공합니다.
