# 02. Interfaces (인터페이스)

인터페이스는 객체의 구조를 정의하는 '설계도'와 같습니다. 코드 내에서 타입을 정의하고, 여러 곳에서 재사용하며 확장할 수
있는 강력한 도구입니다.

---

## 📘 주제별 실습 안내

### 1. 기본 레이아웃 (Basic Interface)

- **파일**: `01-basic-interface.ts`
- **설명**: 객체가 가져야 할 속성명과 타입을 정의하는 가장 기초적인 방법입니다.

### 2. 선택적 속성과 읽기 전용 (Optional & Readonly)

- **파일**: `02-optional-readonly.ts`
- **설명**: 
  - `?`: 필수값이 아닌 속성을 정의합니다 (선택적 속성).
  - `readonly`: 객체 생성 후 값을 변경할 수 없도록 보호합니다 (읽기 전용).

### 3. 인터페이스 확장 (Extension)

- **파일**: `03-interface-extension.ts`
- **설명**: `extends` 키워드를 사용하여 기존 인터페이스의 속성을 모두 상속받고 새로운 속성을 추가할 수 있습니다.

---

## 💡 왜 인터페이스를 사용하나요?

1. **일관성**: 팀 단위 개발 시 객체의 구조를 강제하여 실수를 줄입니다.
2. **유연성**: 구현체와 인터페이스를 분리하여 더 유연한 코드를 작성할 수 있게 합니다.
3. **확장성**: 기존의 타입을 기반으로 손쉽게 새로운 타입을 파생시킬 수 있습니다.

---

> [!NOTE]
> `type` 키워드와 `interface`는 유사하지만, 인터페이스는 선언 병합(Declaration Merging)이 가능하고 확장에 더 특화되어
> 있다는 차이점이 있습니다. 기초 단계에서는 객체 구조 정의 시 인터페이스 사용을 권장합니다.
