# Inbox

`.inbox/`는 조사·계획·검토·인계의 **비정본 작업 근거**를 보관한다. 정책·deck state를 대신하지 않는다.
`.inbox/README.md` 외의 작업 기록을 Inbox 밖의 저장소 파일에서 직접 참조하지 않는다.

## 작업별 진입점

- 기존 자료 찾기·경로·`00-` 번호·문서 번들 → [배치](.configs/guides/organization.md)
- 자유 형식 기록 작성 → [작성](.configs/guides/writing.md)
- 종료·보존·삭제 판단 → [정리](.configs/guides/lifecycle.md)
- 선택적 작성 양식 → [Research](.configs/templates/research.md) · [Plan](.configs/templates/plan.md) ·
  [Review](.configs/templates/review.md) · [Handoff](.configs/templates/handoff.md)

**해당 문서만 읽는다.** 양식이 정해졌다면 템플릿으로 바로 이동하고, 새 경로·번호·번들을 정할 때만 배치 가이드를 추가로
읽는다. 기존 기록을 먼저 재사용하고, 규칙 변경만을 위해 일괄 이동·개명하지 않는다. 템플릿 사용 시 placeholder·안내
주석·불필요한 섹션은 제거한다.
