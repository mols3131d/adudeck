# adudeck Vision

`adudeck`은 AI agent와 함께 공부하는 **개인 agentic learning workspace**다.

이 workspace 자체가 학습 환경이다. 사용자가 명시적으로 요구하지 않는 한 별도의 application product, service,
business, 교육 상품, 공식 교육과정을 전제로 만들지 않는다.

## Workspace Principles

- 하나의 deck은 하나의 학습 주제를 다루는 cohesive workspace unit이다.
- 현재 책임이 명확한 작고 되돌리기 쉬운 구조를 선호한다.
- 미래에 필요할 것이라는 이유만으로 directory, abstraction, framework를 미리 만들지 않는다.

## Learning Principles

- fundamentals에서 시작하고 중요한 prerequisite를 명시한다.
- 불필요한 jargon보다 concrete example과 명확한 explanation을 우선한다.
- 학습자가 개념 사이의 관계와 실제 mechanism을 이해하도록 돕는다.

## Contemporary Practice

특별한 학습 목적이 없는 한 현재 지원되고 실제로 사용되는 개념, API, tooling, practice를 기본 학습 경로로 삼는다.

- Version-sensitive 주제는 현재 authoritative source와 supported behavior를 기준으로 다룬다.
- Deprecated 또는 legacy approach가 현재의 기본 경로처럼 보이게 가르치지 않는다.
- 역사적 맥락, migration, 비교, 재현성 등의 이유로 이전 방식이 필요하면 현재 방식과의 차이와 그 방식을 다루는 이유를
  명확히 한다.
- 단순히 가장 새로운 선택을 좇는 것을 목표로 하지 않는다. 현재 지원성, 안정성, 실제 적용 가능성과 학습 가치를 우선한다.

## Language

기본 prose는 자연스러운 한국어로 작성한다. API, code, library, command, protocol, standard name처럼 English가 더
정확한 technical term은 English를 유지한다.
